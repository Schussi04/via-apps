📱 App & Datensicherung

Dein Lernfortschritt wird nur auf diesem Gerät gespeichert. Sichere ihn regelmäßig, damit nichts verloren geht – z. B. vor einem Gerätewechsel.

So kommt die App auf den Startbildschirm

iPhone/iPad: In Safari öffnen → Teilen-Symbol □↑ → „Zum Home-Bildschirm“.
Android: In Chrome öffnen → Menü ⋮ → „App installieren“ (oder Button oben).
PC/Mac: In Chrome/Edge rechts in der Adresszeile auf das Installieren-Symbol klicken.
Danach startet Via Italiana wie eine normale App – im Vollbild und auch ohne Internet.
